## 📚 Topics Covered

### Core Definitions

- Data
- Database
- DBMS (Database Management System)

### Why Use a DBMS?

- Safety
- Easy to Use
- Reliability
- Fast Data Access

### Types of DBMS

#### Hierarchical DBMS

- Parent-Child Structure
- Tree-Based Organization
- Path-Based Navigation

#### Network DBMS

- Multiple Parent Relationships
- Flexible Connections
- Set-Based Navigation

#### Relational DBMS (RDBMS)

- Tables
- Rows and Columns
- Keys and Relationships
- SQL Queries

#### NoSQL DBMS

- Unstructured Data
- Flexible Schema
- High Scalability

#### Object-Oriented DBMS (ODBMS)

- Objects
- Methods
- Inheritance
- Encapsulation

#### Graph Database

- Nodes
- Edges
- Relationships

#### Document Database

- JSON Documents
- XML Documents
- Flexible Structure

### Database Architectures

#### Centralized Database

- Single Location Storage
- Easy Management
- Consistent Data

#### Distributed Database

- Multiple Locations
- Scalability
- Fault Tolerance
